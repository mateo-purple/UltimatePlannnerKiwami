# アルティメットプランナー極み(仮)

Java製のAndroid予定・タスク管理アプリです。既存の授業用 `ExSample` とは独立したAndroid Studioプロジェクトです。

## 起動方法（Windows）

1. ZIPを展開します。
2. Android Studioの **File > Open** から `UltimatePlannerKiwami_AndroidStudio` フォルダを選択します。`app` や `java` フォルダではありません。
3. 初回はインターネットに接続して **Sync Project with Gradle Files** を実行してください。Gradle 8.9、Android Gradle Plugin 8.7.3、ML Kit日本語OCRなどが取得されます。
4. 不足するSDK 35がある場合、Android Studioの案内に従ってインストールしてください。Android SDK 26以上の端末またはエミュレーターを選び、上部の **Run ▶** を押します。
5. Android 13以降では、締切通知を使うため通知権限を許可します。

推奨: JDK 17（Android Studio内蔵のGradle JDKで構いません）。アプリIDは `jp.ultimateplanner.kiwami` です。

## 画面と機能

- **ホーム:** 今日の固定予定と自動割当、未完了の優先タスク、期限間近の件数、未配置の作業時間を確認。
- **予定表:** 前後の週に切り替えて、固定予定・自動配置されたタスク時間を確認。タップで編集。
- **タスク:** 期限・難易度・残り作業時間・進捗から優先順位を自動計算。進捗変更、完了処理、削除。
- **登録・編集:** タスクと固定予定の2種類、カテゴリ（課題・授業・就活・アルバイト・私用）、締切、所要時間、難易度、進捗、メモ、毎週繰り返し。
- **自動配置:** 固定予定を避け、設定した作業可能時間・集中時間の範囲で、締切に近いタスクから空き時間に自動配置。進捗・予定・設定の更新に合わせて再計算。
- **画像・共有からの登録:** 画像選択後の日本語OCR、Androidの共有メニューで送った画像・テキスト、クリップボード、直接入力。
- **完全自動登録:** 読み取りが完了したら確認画面なしでSQLiteに保存。連続した日付付き行から複数件を取り込む場合もあります。重複データの検出、保存後の編集・取り消しに対応。
- **締切通知:** 期限前日と2時間前の通知。通知の設定変更、端末再起動時の再設定。
- **保存:** SQLiteを使うためアプリを終了しても残ります。

## 共有から登録する

1. スマホでeシラバスなどを開き、表示中の課題・予定をスクリーンショットにします。
2. Androidの共有メニューでこのアプリを選びます。あるいはアプリ右上の取り込みボタンから画像を選びます。
3. OCR完了と同時に予定が確定保存されます。自動解析なので、必要な場合だけ登録結果の「編集する」で直してください。

テキストの共有でも同様です。直接共有されたURLだけではログインが必要なページの中身を取得できないため、内容のスクリーンショットを使ってください。

## 制約・補足

- 画像からの文字認識は端末上のGoogle ML Kit日本語OCRです。OCRおよび日付・時間の抽出は確率的・規則ベースのため、認識に失敗したり、誤登録する場合があります。
- **ユーザーの指定どおり、保存前の確認ダイアログは出しません。** 保存済み一覧から編集・削除可能です。
- eシラバスへのログインや認証済みページの直接取得、Firebaseを設定すればAndroid・Web間の予定同期を利用できます。Firebase設定がない状態では従来どおり端末内保存です。
- 通知はOSの省電力制限により、予定時刻から遅れる場合があります。
- 予定の空き時間割当はアプリ内部で計算した表示です。Googleカレンダー等の外部サービスへ予定を書き込むものではありません。
- ビルドの初回セットアップにネット接続が必要です。本アーカイブはソース・リソースを備えたプロジェクトで、APKは同梱していません。

## Gradleについて

この作業環境に公式Gradle Wrapper JARの取得手段がなかったため、`gradle/wrapper/gradle-wrapper.jar` は単純な独自ブートストラップ（ソースは `tools/wrapper-source/GradleWrapperMain.java`）です。`gradle-wrapper.properties` から公式Gradle 8.9配布ZIPをHTTPSで取得し実行します。Android Studioの通常のGradle Syncで利用できますが、組織ポリシー等で独自のWrapperを禁止している環境では公式のWrapperに置き換えてください。

## PC・iPhoneとの同期（追加機能）

このリポジトリの `docs/` はブラウザ版、`app/` はAndroidアプリです。ブラウザ版は週間時間割、固定予定・毎週の繰り返し、タスク、空き時間への自動配置、オフライン保存に対応します。

同期にはFirebaseプロジェクトが必要です（無料枠あり）。Firebase Authenticationの「メール/パスワード」、Cloud Firestoreを有効にし、`firestore.rules` のセキュリティルールを適用してください。

ブラウザ版の「設定 → クラウド同期」にFirebase Project ID、Web API Key、Web App ID、Auth Domainを入力します。Android版の「設定 → 端末間の同期」に同じProject IDとWeb API Keyを入力し、両方とも同じメール・パスワードでログインしてください。Android版はREST APIを使うため `google-services.json` や追加のFirebase SDKは必要ありません。

同期対象は予定とタスクです。期限通知・作業可能時間帯などの端末固有設定は同期しません。両端末で同じ予定を同時編集した場合は`updatedMs`が新しい変更を優先します。Androidは画面復帰時または同期画面の手動操作時、WebはFirestoreの変更通知で更新します。オフライン中の変更は端末に残り、次の同期で送信します。

このコードにはFirebaseの実プロジェクト設定・秘密のメールやパスワードは含めていません。

## v5：週間時間割の表示・高速化

- 起動時は週間予定表を直接表示します。7日×24時間の時間割で、縦方向に時刻、横方向に曜日を移動できます。最初は午前7時付近から表示します。
- 描画の重いソフトウェアレイヤーを廃止し、専用の縦スクロール領域を使用しました。
- 固定予定の表示ではタスク自動配置を重複実行しません。
- 毎2分のクラウド自動ポーリングと、変更ゼロ件でも画面を再構築する処理を削除しました。画面復帰時と手動操作時には従来どおり同期可能です。
- Android Studioで古いCloudSync_v4ではなく、このFastWeek_v5フォルダをプロジェクトとして開いてください。同じアプリIDで既存SQLiteを維持します。アプリのアンインストールや「データを消去」はしないでください。

この作業環境ではAndroid SDK／エミュレーターが使用できないため、Androidの実機描画とAPKビルドは未検証です。

## v6：画像取り込みでカメラを直接起動

- 画面右上のカメラアイコン／ホームの「カメラで登録」から、端末のカメラを直接起動します。
- 撮影画像をフル解像度のままML Kit日本語OCRへ渡し、読み取れた予定を自動登録します。
- キャンセルしてもアプリに戻れます。撮影画像は処理後にキャッシュから削除します。
- 共有メニューで届いた画像・文章はそのまま処理し、カメラは起動しません。
- 取り込み画面には「保存画像を選ぶ」も残しています。
- 外部カメラへの一時的なURIアクセスには独立したContentProviderを使用します。カメラ権限・ストレージ権限や追加ライブラリは不要です。
- 端末・カメラアプリによってはACTION_IMAGE_CAPTUREの対応が異なるため、実機での確認が必要です。
